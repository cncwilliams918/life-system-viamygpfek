LIFE SYSTEM — XP REFERENCE
Last updated: 2026-08-11

This file tracks every XP source in index.html and its current value.
Update this file any time an XP amount or mechanic changes in the app.

ROUTINE CHECK-INS
  XP per check-in depends on the routine's difficulty (5-dot rating, set on the Routines tab):
    Level 1 (1 dot)   10 XP
    Level 2 (2 dots)  20 XP
    Level 3 (3 dots)  30 XP  <- default for new/unrated routines
    Level 4 (4 dots)  40 XP
    Level 5 (5 dots)  50 XP
  Streak bonus: 20% of the difficulty XP, per day of that routine's longest streak
    e.g. Level 3 (30xp) -> 6 XP per day of longest streak
  Unchecking a check-in removes its XP immediately (XP is always a live reflection
  of current data, not a permanent ledger — this applies everywhere below too).

  Silent routines (Routines tab, "Timeblock only" toggle): still occupy their slot
  on the Weekly Schedule, but get no check-in row on Goals, so no new check-in XP
  or streak-bonus XP accrues while silent. XP already earned before going silent
  is not clawed back (totalXP sums historical dates regardless of the silent flag).

PERFECT DAY BONUS
  +25 XP on any day where every currently-active, TRACKED (non-silent) routine
  scheduled that day got checked in. Silent routines are excluded from the
  requirement entirely, so they can't block the bonus for everything else.
  Deliberately hidden: no progress counter shown beforehand. Only reveals itself
  as a one-line note in the Goals-tab reward summary after it's been earned that day.

TO-DO LIST
  Opening the To-dos tab:     +1 XP, once per calendar day, completely silent (never shown)
  Creating a to-do:           +1 XP per to-do that currently exists
  Completing a to-do:         +3 XP per to-do currently marked done
    (unchecking a completed to-do removes its +3, same live-derivation rule as above)

LEVELING CURVE
  Level N requires 50*N XP to advance to level N+1 (cumulative — Level 1->2 needs
  50 XP, Level 2->3 needs 100 more, Level 3->4 needs 150 more, etc.)

check-ins). Was cosmetic only, no XP attached — removed at user's request.
